# DESIGN.md — 架构设计文档

## 1. 算法背景

脉动阵列（Systolic Array）是一种规则的数据流计算架构，特别适合矩阵乘法。

对于 C = A × B（A: M×K, B: K×N, C: M×N）：

```
C[i][j] = Σ(k=0 to K-1) A[i][k] × B[k][j]
```

每个 PE(i,j) 负责计算一个 C[i][j] 元素，通过 K 次累加完成。

## 2. 数据流设计

### 2.1 时间对齐

核心约束：对于 PE(i,j)，A[i][k] 和 B[k][j] 必须在**同一时钟周期**到达。

```
A[i][k] 到达 PE(i,j) 的时间 = i + k + j（从周期 0 开始）
B[k][j] 到达 PE(i,j) 的时间 = i + k + j
```

两者相等，数据自然对齐。

### 2.2 边界输入

- **左边界** PE(i,0)：在周期 i+k 接收 A[i][k]
- **上边界** PE(0,j)：在周期 k+j 接收 B[k][j]

### 2.3 内部传播

- A 数据：从左到右，每经过一个 PE 延迟 1 周期
- B 数据：从上到下，每经过一个 PE 延迟 1 周期

## 3. 模块设计

### 3.1 Processing Element (pe.v)

```
         a_in                a_out
          ↓                    ↑
    ┌─────────────────────┐
    │    ┌───┐             │
    │    │ × │ → accum     │
    │    └───┘    ↓        │
    │         ┌──────┐     │
    │         │accum │ → result
    │         └──────┘     │
    │    ┌───┐             │
    │    │reg│ → b_out     │
    │    └───┘             │
          ↑
         b_in
```

功能：
- `accum += a_in × b_in`（在 en 有效时）
- `clear_acc` 清零累加器
- `a_out` / `b_out` 是输入数据的寄存器延迟版本（传递给邻居）

时序：
- 累加结果在 en 有效后的下一个时钟沿更新
- a_out / b_out 同样延迟一个周期

### 3.2 Systolic Array (systolic_array.v)

```
FSM 状态机：

    ┌──────┐  start   ┌──────┐  feed_done  ┌──────┐  drain_done  ┌──────┐
    │ IDLE │ ───────→ │ FEED │ ──────────→ │DRAIN │ ───────────→ │ DONE │
    └──────┘          └──────┘             └──────┘              └──────┘
       ↑                                                                  │
       └──────────────────────────────────────────────────────────────────┘
```

- **IDLE**：等待启动信号（a_valid && b_valid）
- **FEED**：每周期喂入 K_DIM 组数据，PE 执行累加
- **DRAIN**：等待流水线排空（M+N 周期），PE 停止 en
- **DONE**：c_valid 有效，一个周期后回到 IDLE

累加器清零时机：在 IDLE 和 DONE 状态（clear_acc 有效），确保进入 FEED 前累加器为零。

### 3.3 流水线延迟

```
总延迟 = M_ROWS + N_COLS + K_DIM 个时钟周期

分解：
  - K_DIM 周期：数据喂入
  - M_ROWS - 1 周期：最后一行数据传播到最下方 PE
  - N_COLS - 1 周期：最后一列数据传播到最右方 PE
  - 1 周期：结果寄存器延迟
```

## 4. 参数化设计

| 参数 | 说明 | 影响 |
|------|------|------|
| M_ROWS | A 的行数 | PE 阵列行数，左边界输入数 |
| K_DIM | A 的列数 / B 的行数 | 喂入周期数，PE 内部累加次数 |
| N_COLS | B 的列数 | PE 阵列列数，上边界输入数 |
| DATA_WIDTH | 数据位宽 | PE 内部乘法器大小 |
| ACCUM_WIDTH | 累加器位宽 | 需足够容纳 K 次累加不溢出 |

建议：`ACCUM_WIDTH >= DATA_WIDTH * 2 + $clog2(K_DIM)`

## 5. 接口协议

```
输入端：
  - a_valid && b_valid 同时拉高启动计算
  - 每周期送入 a_data[i] = A[i][k]，b_data[j] = B[k][j]
  - 送完 K_DIM 个周期后拉低 valid

输出端：
  - c_valid 拉高时，c_data 包含最终结果
  - busy 信号指示计算进行中
```

## 6. 测试策略

测试平台包含三组测试：
1. **已知值测试**：A[i][k]=i+k+1, B[k][j]=k+j+1，便于手动验证
2. **随机测试**：随机有符号值，覆盖一般情况
3. **单位阵测试**：A 全 1，B 为单位阵，验证基本正确性

每组测试对比软件计算的期望结果和硬件输出。
